# 馒头保活（MoviePilot V3）

## 功能

- 通过 MoviePilot 的浏览器 SDK 打开有界面 Chromium，由用户手动完成馒头登录和邮箱验证码。
- 将浏览器 cookies、localStorage（随 `storage_state` 保存）和 sessionStorage 保存到插件数据目录。
- 按配置的间隔，以无头浏览器访问站点首页，并更新浏览器状态。
- 提供立即执行一次的验证入口和最近一次运行状态。

## 安装与配置

1. 在 MoviePilot 插件市场安装本插件。
2. 在配置中填写自己实际使用的馒头站点地址。
3. 勾选“打开人工登录窗口”并保存配置。
4. 在弹出的有界面浏览器中，手动完成登录和邮箱验证码。不要关闭浏览器，等待插件提示状态已保存。
5. 勾选“立即执行一次保活”并保存，确认能正常访问；之后再启用定时保活。
6. 设置保活间隔，默认 6 小时，最小 1 小时。

## 登录态与安全

- 登录态文件写入 MoviePilot 插件数据目录，不写入插件源码目录或 Git 仓库。
- 登录态文件包含 cookies / token 等敏感凭据，请勿分享、提交 Git 或截图泄露。
- 插件不会读取、输出或上传邮箱验证码、Cookie 或 Authorization 值。
- 插件不会自动绕过 Cloudflare 或其他安全验证；遇到挑战页需要用户人工处理。
- “页面访问成功”不代表站点一定认可账号活跃，也不等于账号状态已由站点接口确认。实际效果需以站点端状态为准。

## 说明

本插件通过访问配置的站点首页进行保活，不调用未经确认的私有 API。不同馒头域名或站点前端改版可能影响登录态恢复和登录表单检测。
